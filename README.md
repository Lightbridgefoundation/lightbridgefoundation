# LightBridge Foundation Website

Official website for **LightBridge Foundation**, a grassroots, 100% volunteer-led charity based in Western Sydney, NSW, made up primarily of African immigrants and refugees.

> Lighting the way. Building brighter futures.

- ACNC-registered charity and Public Benevolent Institution
- ABN 89 859 003 724 · INC 2400448
- 24 to 27 Crescent St, Holroyd NSW 2142
- info@lightbridgefoundation.org.au

## Programs

Weekly food relief and food hampers, youth mentoring (ages 8 to 24), casework and advocacy, community support and referrals, cultural events, and annual community excursions that build connection, cohesion and belonging for CALD families.

## Tech stack

- React 19 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Framer Motion, GSAP ScrollTrigger, Lenis

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
```

## Deployment

The built site in `dist/` is static and can be hosted on any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
